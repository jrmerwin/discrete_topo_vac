# B0 to K*0 prediction cards

## Forward predictions

[Prediction card v0.2](prediction_card_v0.2.json), registered 2026-10-16, extends the unchanged May [v0.1 lock](prediction_card.json) with the S7–S9 absorptive null, lepton universality, and C9 flatness/helicity discriminators. S7–S9, the electron angular measurements, the muon-minus-electron fit, the central-bin R_K/R_Kstar ratios, and the older C9-bin extractions are registered against existing data; forward component = Run 3 (and Belle II for electrons). These additions are not part of the May lock. Mechanism-discriminator dangers yield amber, while the original red conditions retain priority. The repository's original forward description is in [forward_prediction.md](../forward_prediction.md).

## Run and reproduce

From the repository root, using Python 3.11 and the versions in `beta_decay/requirements.txt`:

```powershell
python -m pip install -r beta_decay/requirements.txt
python beta_decay/test_score_deu_b2kstar.py
python beta_decay/score_deu_b2kstar.py --card beta_decay/prediction_card_v0.2.json --measurements beta_decay/lhcb_2025_measurements_flavio_angles.csv --fits beta_decay/lhcb_2025_fit_results.csv --c9-bins beta_decay/lhcb_2025_c9_bins.csv --out-dir beta_decay/v02_first_score
```

The test runs v0.1 byte comparisons first, with and without its original fit input. It then tests the new calculations on synthetic data only. The frozen reference is five angular matches, five hits, Z = 5.883356999671099; all four CSV/JSON outputs must match the pre-extension fixtures. The default card is still v0.1 and `--prediction-card` remains an alias for `--card`. To reproduce v0.1 with the original inputs, use `regression_fixtures/measurements_v01.csv` and optionally `regression_fixtures/fits_v01.csv`. No v0.2 data-scoring run is permitted until the implementation/card commit and annotated `card-v0.2` tag exist. The first v0.2 output is committed afterwards.

`prepare_v02_measurements.py` transcribes the local source tables and computes flavio baselines; `prepare_v02_card_and_fits.py` rebuilds the extension card and fit/C9 CSVs without invoking scoring. Flavio uses the original method: binned observables, N=30 uncertainty samples, threads=1, and the Windows fork-to-spawn fallback. New baselines use a recorded NumPy seed; existing baselines and numeric strings are preserved. A missing observable baseline stays empty and unscored. Flavio warns that its QCDF corrections above q2=6 should not be trusted; the 6–8 bin retains that model limitation, as does the corresponding v0.1 comparison.

## Inputs and interpretation

* **Absorptive observables:** `sources/fit_summary_si_s1c_bin_{0,1,2,3,4,8}_with_corrections.tex`, configuration (i), from LHCb-PAPER-2025-041 ([arXiv:2512.18053](https://arxiv.org/abs/2512.18053)). Each added CSV row identifies table, source line, units, error convention, and flavio version. All below-J/psi tables are included, including the integrated 1.1–6.0 bin. That integrated bin overlaps three narrower bins. The requested diagonal-error null chi2 therefore is a diagnostic, not an independence-calibrated joint significance; the CSV does not contain the required covariance. Both warnings and dangers are reported per row.
* **Electron observables:** [arXiv:2502.10291v2, Table 3](https://arxiv.org/html/2502.10291v2#S8.T3) reports P5p and AFB in 1.1–6.0. Two integrated predictions score them once each. The six original-bin electron counterparts are retained for future measurements with weight 1, and currently have no matching data. No finer electron bins or electron rate are inferred. Empty lepton labels mean mu; predictions without a lepton key ignore the column, as specified.
* **LFU fit:** [arXiv:2607.03531, Table 3 and Eq. 33](https://arxiv.org/html/2607.03531) gives C9,e minus C9,mu. The selected Data Driven / LQCD DM interval is sign-reversed to mu minus e; its 68% HPDI midpoint and half-width are used as an explicitly approximate Gaussian representation. Other theory choices are not mixed as independent replicates.
* **LFU ratios:** [arXiv:2212.09152v2, central-q2 results following Fig. 2](https://arxiv.org/html/2212.09152) uses the LHCb Run 1+2 2011–2018 9 fb^-1 sample. It overlaps the angular-analysis data-taking period but has a different selection. R_K and R_Kstar are separate two-sided fit tests of 1. Statistical and systematic asymmetric half-widths are averaged separately, then combined in quadrature.
* **Older flatness inputs:** `dataset=bordone_isidori_tinari_2024` means the earlier LHCb dataset, before the 2025 full angular analysis. All 35 scored points come from [arXiv:2401.18007v2, Tables 3.3–3.4](https://arxiv.org/html/2401.18007v2): LHCb-only K rows, and all tabulated K* helicities/bins. Constant-fit rows and alternative CMS K extractions are excluded. These are older-data tests; their forward component is Run 3. No 2026 figure has been digitized into the scored CSV. Absolute C9 values are expressed relative to one common flavio short-distance C9 coordinate at 4.2 GeV; the offset cancels identically in flatness, slopes, and pooled tests. This is not a new determination of delta C9 in a matched renormalization scheme. Asymmetric marginal errors are averaged; correlations are unavailable. The boundary interval at K, 19–20 (0 with -0/+1.6) is treated with the same rule, so its Gaussian approximation is particularly limited.
* **Long-distance-constrained extraction:** [arXiv:2607.09458, Eq. 5.3](https://arxiv.org/html/2607.09458#S5.E3) reports C9_SM minus C9_fit = +0.52 +/-0.25. The separate fit dataset reverses the sign to the card convention, -0.52 +/-0.25, retaining the published total error. It tests the unchanged [-1.4,-0.4] window under a different theoretical treatment of the same 2025 data. It is not independent of the original C9 fit row. This parameter extraction does not replace any flavio angular baseline.
* **Dispersive S7–S9 baseline:** Section 5.3 / Fig. 5.4 of the same 2026 paper supplies figure-only postdiction bands, not a numerical table. `baseline_ld` and `baseline_ld_err` are separate from `sm_value`/`sm_err`; without author-provided numbers they remain empty, explicitly unscored. If supplied later, the scorer writes descriptive pulls to `ld_baseline_scored.csv` without replacing the registered flavio null or changing classification. These are conditioned postdictions, and their fit uses the first S7 bin to help set Im(C7); they must not be presented as independent predictions. No conclusion about numerical agreement with the LD baseline is asserted here.

Within each C9 helicity group the scorer computes an inverse-variance mean, chi2 with n-1 degrees of freedom, and a weighted slope with its supplied-error uncertainty. Singleton groups have no chi2 p-value or slope significance. A second chi2 across the independent-error group means tests helicity/channel independence. `flat_danger_count` includes within-group and pooled dangers; `helicity_p` is the pooled p-value. None of these diagonal approximations reproduces the full likelihood or covariance-aware fits in the source papers.

The operational S7–S9 null tests a specific SM baseline. A real C9 change can still modify interference with existing SM strong phases; the null is a discriminator of the simple card interpretation, not a general theorem ruling out all real-C9 models.

## Release sequence

Only `beta_decay/` is changed. The v0.2 card, inputs, scorer, regression fixtures, and documentation form the registration commit. Its annotated tag contains the card's single SHA-256, also recorded in the release description. The first scoring run and its complete warnings/dangers live in a later commit. The GitHub–Zenodo webhook must archive the tagged registration commit as a new version under concept DOI [10.5281/zenodo.20019885](https://doi.org/10.5281/zenodo.20019885), preserving the May version [10.5281/zenodo.20019886](https://doi.org/10.5281/zenodo.20019886). Zenodo API metadata identifies 20019885 as the concept; 20019886 is the existing v1.0 version DOI. Publication status and any new version DOI must be checked rather than assumed from webhook configuration alone.
